# 👗 FashionPicks

**FashionPicks** is a modern frontend-only React application where users can post outfit polls, vote on others' looks, and interact with a style-focused social community. It’s designed to help users decide what to wear by crowdsourcing feedback.

## ✨ Features

- 🔐 User Login and Registration
- 🏠 Home page showing polls from followed users
- 📊 Create dress polls to get opinions
- 👥 Follow/unfollow other fashion enthusiasts
- 👤 Edit and customize user profiles
- 🚫 Block/report users for safety
- 💬 Interactive user experience and engagement

## 🧰 Tech Stack

- **Frontend**: ReactJS
- **Routing**: React Router
- **Styling**: Tailwind CSS (or other framework if used)
- **State Management**: Context API / Redux (if used)
- **Session Handling**: LocalStorage for auth tokens and session data
